Copier Calendar Timesheet

Accès anticipé. Calendar Timesheet se présente sous la forme d’une feuille de calcul prête à l’emploi, avec le module complémentaire intégré. Vous la copiez dans votre propre Google Drive ; dès lors, elle vous appartient et ne s’exécute que dans votre compte.

Pas à pas

  1. Créez une copie. Le bouton ci-dessus ouvre Google Sheets, qui demande « Copier le document ? ». Cliquez sur Créer une copie. La copie arrive dans votre Google Drive.
  2. Ouvrez le module complémentaire. Dans votre copie, ouvrez le menu Extensions, puis Calendar Timesheet, puis Ouvrir. Si le menu n’apparaît pas encore, patientez quelques secondes ou rechargez la page.
  3. Autorisez-le. Google affiche « Autorisation requise ». Cliquez sur Continuer et choisissez votre compte Google.
  4. Passez l’avertissement de Google. Google affiche « Google n’a pas validé cette application ». Cliquez sur Paramètres avancés, puis sur Accéder à Calendar Timesheet (non sécurisé). La section ci-dessous explique pourquoi cet écran apparaît.
  5. Vérifiez les autorisations listées par Google et cliquez sur Autoriser. Le tableau ci-dessous indique à quoi sert chacune d’elles.
  6. Lancez la configuration. Le panneau s’ouvre à droite : cochez vos agendas, nommez vos clients, activez le pilote automatique.

Pourquoi Google affiche un avertissement

Quand vous copiez une feuille de calcul qui contient un script, la copie et son script vous appartiennent. Google affiche le même avertissement pour tous les scripts qu’il n’a pas examinés, y compris ceux que chacun écrit pour lui-même. Cela ne signifie pas qu’un problème a été détecté.

Vous pouvez lire chaque ligne du code avant de l’autoriser : dans votre copie, ouvrez Extensions, puis Apps Script.
